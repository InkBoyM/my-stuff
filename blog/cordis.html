We have launched a new KSF product: Cordis!

What is Cordis?

If you haven't heard of Cordis, what are you doing?!? Everyone has heard of Cordis, even Mr. President himself:

"I do quite like Cordis actually, its good for because it was made in the USA instead of China China China"
— Not actually Donald Trump

Cordis is a chatting app made by ryanthestupid, inkboym, and eicv_ as part of KillSecurly (KSF) & LVMlabs. It's aiming to be an unblocked chatting app for students to use in school to chat with each other — it has a lot of features like creating servers, DMs, profile customization, and more!

Cordis is very new (around 2 months old) and we are still adding new features.

We are heavily inspired by Discord if you couldn't tell by going onto the site.

Cordis is open source — you can also self host your own version of Cordis for private use!

What features does Cordis have?

Messaging

  • ☑ Message formatting
  • ☑ Edit message
  • ☑ Delete message
  • ☑ Reply to message
  • ☑ Emoji reactions
  • ☑ Working pings
  • ☑ Highlighted pings
  • ☑ Highlighted links
  • ☑ Last seen indicator

Embeds & Attachments

  • ☑ Rich embeds
  • ☑ YouTube rich embeds
  • ☑ In-app video embeds
  • ☑ Correct attachment handling

Permissions & Roles

  • ☑ Administrator (system-level)
  • ☑ Moderator (system-level)
  • ☑ Admin powers (ban, etc.)
  • ☑ Mod powers (mute)
  • ☑ Server roles
  • ☑ Server permissions
  • ☑ Server admin

Server Structure

  • ☑ Channel categories
  • ☑ Server icons
  • ☑ Server banners
  • ☐ Join messages
  • ☑ Verified servers
  • ☐ Verified accounts

User & System

  • ☑ Notification sound
  • ☑ Profile picture cropping
  • ☐ Commands

Appearance

  • ☑ Light mode toggle

We still have other features on our list but these are the main ones we are focusing on.

Cordis Releases

Cordis is currently on version 1.1.

Cordis v1.1 — Jul 27 2026

Changelog

  • Servers can be verified by system admins
  • Server roles
  • System admins can force username changes (flagged for change on next startup, user gets discretion on the new name)
  • System admins can force display name changes
  • Homepage / login page updates
  • License added (Apache-2.0)
  • Channel access view updates
  • Cropping for profile pictures and banners
  • Fixed websocket broadcasts crashing connections
  • Bug fixes and other quality-of-life improvements

Contributors: ko6lvm, eicv-dev

Cordis v1 — Jul 16 2026

Features

  • Full desktop and mobile UI on web
  • Notifications, pings, and unread status
  • Servers (admin roles, channels, categories, etc)
  • Light/dark mode
  • Rich embeds, including platforms like YouTube
  • Rich text formatting
  • Profile customization
  • Message reactions, editing, and deleting
  • Python backend
  • Cloudflare R2-like database/CDN for images
  • PostgreSQL messages and account database
